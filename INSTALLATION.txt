TASKFLOW PRO 2.3 - WINDOWS
======================================

ENGLISH
-------
1. Choose the x64 build for 64-bit Windows or x86 for 32-bit Windows.
2. Open TaskFlow.exe. No installation is required.
3. Select Recording A or Recording B.
4. Press F8 to start/finish recording, F9 to play, and F10 to stop.
5. Choose Single to loop the selected recording, or A -> B loop to play both
   recordings consecutively.
6. Use the EN/ES flag button for language and LIGHT/DARK for appearance.
7. Use the title-bar square button to alternate between compact and full view.
   The minus button minimizes normally. Global hotkeys can be changed in Settings.

ESPANOL
-------
1. Elige x64 para Windows de 64 bits o x86 para Windows de 32 bits.
2. Abre TaskFlow.exe. No necesita instalacion.
3. Selecciona Grabacion A o Grabacion B.
4. Presiona F8 para iniciar/finalizar, F9 para reproducir y F10 para detener.
5. Usa Normal para repetir la grabacion seleccionada, o Bucle A -> B para
   reproducir ambas consecutivamente.
6. Usa el boton EN/ES para el idioma y LIGHT/DARK para el tema.
7. Usa el boton cuadrado de la barra de titulo para alternar entre vista compacta
   y completa. El boton menos minimiza normalmente. Los atajos se cambian en Ajustes.

Windows SmartScreen may show a warning because this independent build does not
have a commercial code-signing certificate. The application works locally and
does not send recordings to the internet.
